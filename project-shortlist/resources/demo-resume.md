# Sample Resume

This file ships with the play so it can be run with no setup at all.
It is a SAMPLE, not a real person. `demo=true` compares it against a real public
GitHub account so a first run shows the actual shape of the answer in a few seconds.

Its bullets are written in one consistent style on purpose, so the style matching
has something to measure: a bullet glyph, a past tense opening verb, the stack
after "using", and a closing full stop.
